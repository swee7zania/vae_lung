# Classification implementation

Classification is achieved by building an **MLP (Multi-Layer Perceptron) classifier** based on the latent vectors generated by the **VAE model**. The main steps are as follows:

1. Data preparation: generating classification datasets
2. VAE model training and generating latent vectors
3. MLP classifier architecture definition
4. Cross-validation: dataset division and training
5. Testing and evaluation

```py
/VAE/
├── dirichlet_vae.py      # VAE model class
├── trainer.py            # VAE training class
├── train_vae.py          # Trains VAE model and evaluation

/MLP/
├── mlp_model.py          # MLP model class
├── trainer.py            # MLP training class
├── train_mlp.py          # Trains an MLP classifier using latent vectors

/utils/
├── data_split.py         # Loads metadata and performs K-fold split
├── config.py             # Hyperparameter configuration module
├── main.py               # Main program entry

predict_single_image.py   # Make predictions for a image
```

# VAE Model

###  `dirichlet_vae.py`

**Classes**

- **`ResampleDir(latent_dim, batch_size, alpha_fill_value)`**
  - Handles sampling and KL divergence computation using a Dirichlet prior.
  - **Functions:**
    - `sample(logits)` → Dirichlet samples
    - `prior_forward(logits)` → KL divergence loss
    - `concentrations_from_logits(logits)` → Dirichlet concentration parameters
- **`Conv(in_channels, out_channels, kernel_size, stride=1, padding=0)`**
  - Basic convolutional block with activation and normalization.
  - **Returns:** feature map tensor.
- **`ConvTranspose(...)`**
  - Transposed convolution (deconvolution) block used in decoder.
- **`ConvUpsampling(...)`**
  - Bilinear upsampling block used to reduce checkerboard artifacts.
- **`DIR_VAE(base, latent_size, alpha_fill_value)`**
  - Main VAE model with Dirichlet latent distribution.
  - **Functions:**
    - `forward(x)` → `reconstructed_x, alpha_logits, dirichlet_sample`
    - `encode(x)`, `decode(z)` → intermediate latent operations
    - `loss_function(...)` → total loss combining reconstruction, KL, and SSIM

### `trainer.py`

**Class**

- **`Trainer(params, device, results_path, model)`**
  - Handles training, testing, plotting, and early stopping.

**Methods**

- **`train_model(model, lr, epochs, sample_shape, train_loader, test_loader)`**
  - Trains the model and saves final weights/losses.
  - **Returns:** train_losses, val_losses, ssim_score_list
- **`train(model, epoch, epochs, optimiser, sample_shape, train_loader)`**
  - Performs one training epoch; logs progress; visualizes images.
  - **Returns:** train_loss, ssim_mean, kld
- **`validate(model, epoch, val_loader)`**
  - Runs evaluation on test set and returns losses and SSIM.
  - **Returns:** val_loss, ssim_mean
- **`early_stopping(counter, train_loss, test_loss, min_delta)`**
  - Implements early stopping if test loss doesn’t improve.
- **`plot_results(filename, model_pat)`**
  - Plots and saves training/validation loss curves.

### `train_vae.py `

**Function**

- **`train_vae(train_df, val_df, params, epochs, fold, results_path, device)`**
  - Trains a DIR-VAE model on raw `.npy` images using HU normalization.
  - Saves latent vectors, model weights, reconstruction images, and loss curves for the current fold.
  - Computes final reconstruction quality metrics: SSIM, MSE, L1.
  - **Returns:**
    - `latent_train`: latent vectors of training set
    - `latent_val`: latent vectors of validation set

# MLP Classifier

### `mlp_model.py`

**Classes**

- **`MLP(latent_size, base, layer_sizes, dropout, depth)`**
  - Defines a fully-connected multilayer classifier for binary prediction.
  - Uses 4- or 5-layer GELU-activated architecture with dropout and batch normalization.
  - **Returns:** forward pass output: probability between 0–1

### `trainer.py`

**Classes**

- **`Trainer(params, device, results_path, latent_size, base)`**
  - Manages MLP training, testing, evaluation, and metric logging.

**Methods**

- **`train_model(model, epochs, train_loader, valid_loader)`**
  - Trains MLP on train set, evaluates on val set, applies early stopping.
  - **Returns:** statsrec, results, auc
- **`validate(val_loader, model, threshold)`**
  - Computes binary classification metrics over given loader.
  - **Returns:** val_loss, val_acc, val_outputs, val_labels
- **`confusion_matrix(outputs, labels, threshold)`**
  - Builds confusion matrix for predictions vs. labels.
- **`evaluation_metrics(tp, fp, tn, fn)`**
  - Calculates precision, recall, specificity, and F1 score.
- **`plot_results(filename, model_path, epochs)`**
  - Saves training/validation loss and accuracy plots.

### `train_mlp.py`

**Function**

- **`train_mlp(latent_train, labels_train, latent_val, labels_val, params, epochs, fold, results_path, device)`**
  - Trains an MLP classifier on VAE-extracted latent features.
  - Computes performance metrics including Accuracy, Precision, Recall, Specificity, F1-score, and AUC.
  - Saves model weights, training statistics, and performance metrics for each fold.
  - **Returns:**
    - `metrics`: dictionary of final performance results

# Utils

### `data_split.py` 

**Function**

- **`load_meta_and_images(meta_file, image_dir, k_folds=5)`**
  - Loads the metadata CSV and filters samples where `data_split == Train`.
  - Constructs full `.npy` file paths based on `original_image` column.
  - Performs stratified K-fold split using class `label`.
  - **Returns:**
    - `splits`: list of (train_df, val_df) tuples for each fold

### `main.py` 

**Function**

- **`run_kfold_training(meta_file, image_dir, k_folds, params, epochs, results_path, device)`**
  - Runs the full VAE → latent → MLP pipeline under stratified K-fold cross-validation.
  - Trains and saves results per fold including model checkpoints, latent vectors, metrics, and plots.
  - Logs final performance per fold for MLP classifier.

### `config.py`

**Function**

- **`get_random_hyperparams()`**
  - Samples a dictionary of hyperparameters for both VAE and MLP from a pre-defined discrete search space.
  - Used to randomize training runs for reproducibility and tuning.
